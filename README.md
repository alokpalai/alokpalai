`Python` `PySpark` `SQL` `XGBoost` `SHAP` `Power BI`

**[A/B Testing Analysis](https://github.com/alokpalai/AB-testing-checkout-analysis)**

`Python` `Statistics` `SQL`

**[Product Funnel Analysis](https://github.com/alokpalai/product-funnel-analysis)**
